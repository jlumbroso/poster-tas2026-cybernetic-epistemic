# Companion page — poster for *Cybernetic and Epistemic* (TAS 2026)

Static companion page for the poster of **Cybernetic and Epistemic: A
Missing Vocabulary for Trustworthy Agentic Delegation** (Jérémie
Lumbroso; arXiv:2610.00961), presented at TAS 2026 (Trustworthy Agentic
Systems), an AAAI 2026 Fall Symposium, Arlington, VA, November 6, 2026.

- Page: `https://jlumbroso.github.io/poster-tas2026-cybernetic-epistemic/`
- Poster: `poster.pdf` (40 × 30 in, landscape) and `poster-preview.png`
- Paper: https://arxiv.org/abs/2610.00961

The page links the two decision records the poster quotes (one public,
at a pinned commit; one private, described) and the paper's own public
record (free-disk-space ADR-0007). No build step; GitHub Pages serves the
repository root.

Status line on the page is dated; when results of the reconstruction test
exist, the line is updated with a new date and the old one kept, so the
page shows its status history.

Poster drafted with Claude Fable 5.1 and the author.
